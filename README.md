# RFONLINEAuction

Веб-аукцион за игровые очки для RF Online.

Планируемая архитектура:

- Python backend и база данных для игроков, лотов и ставок.
- Solana для учёта начислений и списаний игровых очков.
- Solana Devnet для разработки и тестирования.

## Простая первая версия

Python-скрипт читает JSON со списком начислений и записывает отдельную неизменяемую
Memo-транзакцию в Solana Devnet для каждого игрока. В записи сохраняются:

- идентификатор операции;
- постоянный `player_id`;
- ник персонажа на момент начисления;
- количество начисленных очков.

Пример данных находится в `players.example.json`.

Проверить файл без отправки транзакций:

```powershell
python send_points.py players.example.json --dry-run
```

Установить библиотеки и отправить данные в Devnet:

```powershell
python -m pip install -r requirements.txt
python send_points.py players.example.json --keypair C:\path\to\devnet-keypair.json
```

Файл ключа нельзя добавлять в Git. Шаблоны `id.json` и `*-keypair.json` уже
исключены через `.gitignore`.

Эта версия хранит журнал начислений. Баланс игрока равен сумме его начислений.
Memo-программа не запрещает повторную отправку одной операции; такую защиту и
списание очков добавим в собственную Solana-программу на следующем этапе.
